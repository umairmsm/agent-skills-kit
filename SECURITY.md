| Version | Supported          |

## Reporting a Vulnerability

We take the security of agentic tooling and development scaffolding seriously. If you discover a security vulnerability (such as insecure file permissions, command injection risks, or credential exposure):

1. **Do NOT open a public GitHub issue.**
2. Send an advisory report via GitHub Private Vulnerability Reporting:
   - Navigate to the repository's **Security** tab and click **Report a vulnerability**.
   - Alternatively, contact the maintainer via `umairmsm@users.noreply.github.com`.
3. Please include:
   - A description of the issue and potential impact.
   - Reproduction steps or minimal example.
   - Any suggested remediations.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix.
